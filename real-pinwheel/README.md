# Real-period pinwheel scheduling at density 5/6

Fabian Fetik · Preprint · 28 September 2026 · v1 · cs.DM / math.CO

<img src="../publishing/site/assets/pinwheel-header.svg" alt="" width="600">

Tasks must recur indefinitely under timing constraints given by real-valued periods. Schedules exist for every finite task family whose reciprocal periods sum to at most 5/6.

**[Read paper (PDF, v1)](https://fabianfetik.github.io/math/real-pinwheel/real-pinwheel-5-6-v1.pdf)** · [Paper page](https://fabianfetik.github.io/math/real-pinwheel/)
